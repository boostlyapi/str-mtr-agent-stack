# STR/MTR Agent Stack Plan

## Goal
The goal of the STR/MTR Agent Stack is to provide specialized AI agents tailored for the unique needs of short-term and mid-term rental operators.

## Core Target Users
*   STR hosts
*   MTR operators
*   Property managers
*   Serviced accommodation teams

## Planned Agents
*   **Guest Concierge Agent**: Handles guest inquiries and local recommendations.
*   **Dynamic Pricing Agent**: Optimizes rates based on local demand and property features.
*   **Cleaning & Maintenance Agent**: Orchestrates turnovers and property upkeep.
*   **Reputation Management Agent**: Automates review responses and guest feedback loops.

## Starter Implementation Status
*   **Guest Concierge Agent**: Initial scaffold and tool logic implemented.
*   **Core Interfaces**: Mock PMS and Claude context handlers are available for development.
*   **No Production Integrations**: All current tools use mock data and do not require live API keys.
